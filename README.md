# Projeto PDS (Java) ☕

Repositório desenvolvido para um Sistema de gerenciamento de estoque para um supercado.

---

### 🚀 Sobre o Projeto
Este sistema faz parte das atividades práticas da disciplina de PDS (Prática e Desenvolvimento de Sistemas), focado em aplicar conceitos fundamentais de lógica, estruturação de código e tratamento de erros.

---

### 🛠️ Tecnologias Utilizadas
* **Linguagem:** Java
* **Ferramentas:** IDE compatível com projetos Java (Eclipse/VS Code)

---

### ⚙️ Como Executar
1. Certifique-se de ter o **Java Development Kit (JDK)** instalado na sua máquina.
2. Clone este repositório ou baixe os arquivos em formato ZIP.
3. Importe a pasta do projeto na sua IDE de preferência.
4. Execute a classe main para testar a aplicação.
